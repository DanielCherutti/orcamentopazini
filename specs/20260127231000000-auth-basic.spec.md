# 20260127231000000 - Autenticação Básica e Layout

Esta especificação define a tela de login inicial e a estrutura de layout (Sidebar/Header) para a nova versão do sistema.

## 1. Contexto e Objetivo
- **Contexto:** Necessidade de uma entrada para o sistema e uma estrutura de navegação.
- **Objetivo:** Implementar tela de login (simples) e o layout administrativo.
- **Mudança:** Login é a Home Page. Clicar em entrar redireciona para o Dashboard.

## 2. Requisitos Funcionais

### 2.1 Tela de Login (Home)
- **Rota:** `/` (Page.js)
- **UI:** Cartão centralizado com título, campos de email/senha (visuais) e botão "Entrar".
- **Ação:** Clicar em "Entrar" redireciona para `/dashboard`.
- **Validação:** Nenhuma complexa por enquanto. Apenas transição de tela.

### 2.2 Layout do Dashboard
- **Rota Base:** `/dashboard` (Layout.js)
- **Sidebar (Lateral):**
  - Fixo à esquerda.
  - Links: "Produtos" (único módulo ativo).
  - Estilo: Dark mode (conforme Design System).
- **Header (Topo):**
  - Título da página atual.
  - Avatar do usuário (mock).
- **Proteção:** (Futuro) Apenas usuários "logados" acessam `/dashboard`. (Por enquanto, livre ou cheque simples de cookie).

## 3. Contratos e Interfaces

### 3.1 Server Actions
- `loginAction(formData: FormData)`
  - Input: email, password.
  - Output: redirect to `/dashboard/products`.
  - Side Effect: Define cookie de sessão (simulado).

## 4. Fluxos
1. Usuário acessa `http://localhost:3000`.
2. Vê tela de login.
3. Clica em Entrar.
4. Redirecionado para `/dashboard/products`.
5. Vê Sidebar com "Produtos" ativo e lista de produtos (vazia inicialmente).

## 5. Critérios de Aceite
- [ ] Acessar `/` mostra login.
- [ ] Botão "Entrar" leva para `/dashboard/products`.
- [ ] `/dashboard` tem Sidebar e Header.
- [ ] Sidebar tem link para Produtos.
- [ ] Design System (Azul/Amarelo) aplicado.
