# 20260129170500000 - Budget Annotations (Anotações Visuais)

Esta especificação define o motor de anotações visuais para os orçamentos, inspirando-se na experiência premium do **Screenpresso**.
O objetivo é fornecer uma ferramenta de desenho vetorial sobre imagens que permita vincular visualmente produtos a locais.

## 1. Contexto e Objetivo
- **Contexto**: Orçamentos técnicos de engenharia exigem evidências visuais claras. Uma foto do local ("Galpão") precisa receber indicações precisas de onde cada produto será instalado.
- **Objetivo**: Criar um componente reutilizável (`<AdvancedImageAnnotator />`) que replique a facilidade de uso e estética do Screenpresso (setas numeradas, sombras, alto contraste) para web.
- **Referência**: Software Screenpresso + `orcamentos.md`.

## 2. Componente de UI: `<AdvancedImageAnnotator />`

Este será um componente isolado e reutilizável (`front/src/components/annotator/`), desacoplado da lógica de negócios do orçamento, recebendo apenas props de configuração.

### 2.1 Estética & "Screenpresso Feel"
Para garantir qualidade visual premium:
1.  **Alto Contraste**: Todos os elementos (setas, textos, números) devem ter **borda branca** (stroke) e **sombra projetada** (drop-shadow) para garantir visibilidade sobre qualquer fundo (escuro ou claro).
2.  **Cores Vibrantes**: Paleta padrão de cores "Neon/Marker" (Magenta, Cyan, Lime, Red Safety).
3.  **Vetorial**: Uso de SVG/Canvas para que nada fique pixelado ao dar zoom.

### 2.2 Ferramentas (Tools)

#### A. Step Tool / Tag Numérica (Principal)
Feature "carro-chefe" inspirada na ferramenta de numeração do Screenpresso.
- **Comportamento**: Clique na imagem cria um "Balão" numerado (①, ②, ③...).
- **Modo Sequencial**: Próximo clique já vem com (n+1).
- **Vínculo**: No contexto do Orçamento, o número ① corresponde visualmente ao **Item #1** da lista de peças.
- **Visual**: Círculo com cor de fundo sólida, borda branca grossa, número centralizado em negrito. Possível "perninha" (pointer) apontando para o ponto exato clicado.

#### B. Arrow Tool (Setas)
- Setas com corpo preenchido (não apenas linha fina).
- Suporte a curvatura (Bezier) ou retas.
- Cabeça da seta proporcional.

#### C. Text Box
- Caixa de texto com fundo semitransparente ou sólido (para cobrir detalhes da foto).
- Padding interno e bordas arredondadas.

#### D. Magnifier (Zoom de Detalhe) - *Nice to have*
- Círculo que mostra um zoom de 2x/4x de uma área pequena da imagem original, para mostrar detalhes de um parafuso ou rachadura.

## 3. Estrutura de Dados (Data Model)
Extensão do modelo definido na Spec 1.

### 3.1 Entidades

#### `budget_image` (Imagem do Local/Trecho)
Representa a foto base enviada pelo usuário.
- `id`: record
- `section_id`: record<budget_section>
- `url`: string (URL da imagem original - limpa)
- `composed_url`: string (URL da imagem "achatada" com anotações impressas - gerada para PDF)
- `width`: number
- `height`: number

#### `image_annotation` (Anotação individual)
- `id`: record
- `image_id`: record<budget_image>
- `tool_type`: string ('step_number', 'arrow', 'text', 'rect')
- `style`: object (Cor, espessura, opacidade)
- `geometry`: object (Coordenadas X/Y relativas em %, para responsividade)
    - `x`: 0.5 (50%)
    - `y`: 0.5 (50%)
    - `points`: [...] (Para setas/shapes)
- `content`: string (Texto ou Número do Step)
- `linked_item_id`: record<budget_item> (Opcional: ID do item de orçamento ao qual esta anotação se refere)

## 4. Integração Técnica

### 4.1 Bibliotecas
- **Engine**: `react-konva` (Wrapper do Konva.js). É a melhor opção para canvas interativo com suporte a eventos (drag, click, hover) e performance.
- **Exportação**: O Konva possui método nativo `.toDataURL()` para gerar a imagem composta (`composed_url`).

### 4.2 Fluxo de Edição
1.  Usuário abre imagem no modal `<AdvancedImageAnnotator />`.
2.  Seleciona ferramenta "Step Number".
3.  Clica na imagem perto de uma viga.
4.  Cria o balão "①".
5.  Abre um popover perguntando: "Vincular a qual produto?".
6.  Usuário seleciona "Guarda-corpo 2m" da lista.
7.  Anotação salva com `linked_item_id`.

### 4.3 Geração de Imagem Composta (Flattening)
Para o PDF, não podemos depender de renderizar vetores.
- Ao salvar, o componente gera um PNG de alta resolução combinando FOTO + VETORES.
- Upload desse PNG para o storage (bucket `composed-images`).
- O PDF usa apenas esse PNG final.

## 5. Casos de Uso

1.  **Levantamento de Campo**: Engenheiro tira foto de um mezanino.
2.  **Marcação**: No escritório, abre a foto e usa a ferramenta "Step" para marcar 3 pontos onde faltam guarda-corpos.
3.  **Associação**: Marca os pontos 1, 2 e 3. Associa todos ao produto "Guarda-corpo padrão".
4.  **Resultado**: Na tabela do orçamento aparece "Item 1: Guarda-corpo (3 unidades)". Na foto aparecem as bolinhas 1, 2 e 3.
