# PAZINI-103 — Cobrança Asaas + Audit Log Visual

**Branch sugerida:** `PAZINI-103` (após PAZINI-101/102)  
**Referências:** `20260620120000000-pazini-101-platform-reseller.spec.md`, `20260620140000000-pazini-102-impersonate-custom-domain.spec.md`

## 1. Objetivo

- **Cobrança integrada:** gerar cobranças reais por organização via **Asaas** (boleto/PIX/cartão), recorrente + avulsa.
- **Audit log visual:** registrar e exibir ações do painel `/platform` e CRUD operacional dentro de cada org.

## 2. Variáveis de ambiente

```env
ASAAS_API_KEY=
ASAAS_ENV=sandbox
ASAAS_WEBHOOK_TOKEN=
BILLING_CRON_SECRET=
```

## 3. Requisitos — Cobrança

- **RF-301:** Perfil de cobrança por org (`billing_email`, `billing_name`, `billing_cpf_cnpj`, `billing_phone`, `asaas_customer_id`, `billing_enabled`).
- **RF-302:** Cobrança manual avulsa no detalhe da org (valor, vencimento, descrição).
- **RF-303:** Job diário gera cobrança de assinatura antes do vencimento da licença (idempotente por `tenant_id + YYYY-MM`).
- **RF-304:** Webhook Asaas atualiza `platform_charge.status`; pagamento de renovação estende `license_expires_at`.
- **RF-305:** Permissões `billing.view` / `billing.write` no RBAC platform.

## 4. Requisitos — Audit

- **RF-401:** Tabela unificada `audit_log` com scope `platform` | `tenant`.
- **RF-402:** Helper `recordAudit()` — falha de audit não bloqueia operação.
- **RF-403:** Instrumentar Server Actions de escrita (platform + tenant CRUD).
- **RF-404:** UI `/platform/audit`, aba Auditoria no detalhe org, `/settings/audit` para admin da org.
- **RF-405:** Permissões `audit.view` / `audit.export`; export CSV (24 meses).

## 5. Critérios de aceite

- **CA-301:** Cobrança manual sandbox gera link Asaas e registro local `pending`.
- **CA-302:** Webhook `PAYMENT_RECEIVED` marca `paid` e renova licença (tipo subscription).
- **CA-303:** Org sem perfil fiscal bloqueia geração de cobrança.
- **CA-401:** Criar produto gera entrada `audit_log` com actor e tenant.
- **CA-402:** Impersonate continua auditado em `audit_log` (migração de `platform_audit_log`).
