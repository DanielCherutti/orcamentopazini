# 20260129171000000 - Budget Output & Templates (PDF/DOCX)

Esta especificação define o motor de geração de documentos finais (Propostas Comerciais), utilizando as imagens anotadas e a estrutura de dados definida nas specs anteriores.

## 1. Contexto e Objetivo
- **Contexto**: O cliente final recebe a proposta em formato PDF (impresso/email) ou DOCX (para edição). A qualidade visual deve ser impecável, respeitando o layout do "Pazini v1".
- **Objetivo**: Implementar um sistema de templates flexível e geradores de documentos (PDF/DOCX) que montem o relatório final combinando: Textos Ricos + Hierarquia de Orçamento + Imagens Anotadas + Anexos.
- **Referência**: `orcamentos.md` e arquivo PDF de exemplo `refs/pazini-v1/docs/proposta-comercial-base-de-exemplo.pdf`.

## 2. Estrategia de Templates Padrão

O sistema terá um template "Mestre" inicial, mas a arquitetura deve permitir múltiplos no futuro.

### 2.1 Seções do Documento (Anatomia)
O documento é composto por blocos sequenciais:
1.  **Capa**: Logo, Título, Dados do Cliente, Data, Versão.
2.  **Apresentação/Institucional**: Texto fixo ou editável (Rich Text) sobre a Pazini.
3.  **Objetivo/Escopo**: Texto editável específico do orçamento.
4.  **Detalhamento Técnico (Loop)**:
    - *Itera sobre Locais*: Título do Local.
    - *Itera sobre Trechos*: Título do Trecho + Descrição.
    - **Galeria**: Exibe a `composed_url` (imagem anotada) do trecho em tamanho grande.
    - **Lista de Itens**: Tabela com Produtos, Quantidades e Preços (referenciados pelos números na foto).
5.  **Resumo Comercial**: Tabela de totais, condições de pagamento, validade.
6.  **Anexos**: Manuais técnicos dos produtos utilizados (opcional/configurável).

## 3. Estrutura de Dados

### 3.1 Entidade `budget_template`
- `id`: record
- `name`: string ("Proposta Padrão 2026")
- `is_default`: boolean
- `structure`: json (Definição dos blocos e ordem)
- `styles`: json (Configuração de fontes, cores, margens)

### 3.2 Rich Text (Campos Descritivos)
Campos como `budget.description` ou `budget_location.description` devem suportar formatação básica (Bold, Bullet Points) para compor o documento.

## 4. Motor de Geração (Engine)

### 4.1 Geração de PDF (`@react-pdf/renderer`)
Utilizaremos `@react-pdf/renderer` para criar o PDF no servidor (Server Action ou Route Handler).
- **Justificativa**: Permite usar componentes React para diagramar o PDF, facilitando a manutenção e estilização (suporta Flexbox).
- **Fluxo**:
  1.  Fetching de todos os dados do orçamento (incluindo `composed_url` das imagens).
  2.  Renderização do componente `<ProposalPDF data={budget} />` para stream.
  3.  Retorno do stream para download.

### 4.2 Geração de DOCX (`docx` library)
Para clientes que exigem arquivo editável.
- **Lib**: `docx` (básica e robusta).
- **Limitação**: O layout complexo do PDF é difícil de replicar perfeitamente no DOCX. Focaremos em entregar o *conteúdo* estruturado corretamente (Tabelas, Imagens, Textos), aceitando que a formatação visual será mais simples que o PDF.

### 4.3 Anexos de Produtos
- Cada Produto no cadastro tem um campo `technical_manual_url` (PDF).
- Na geração da proposta final, se a opção "Incluir Manuais" estiver marcada:
  - Usar `pdf-lib` para fazer **Merge** do PDF da proposta (gerado no passo 4.1) com os PDFs dos manuais dos produtos listados.
  - O resultado é um único arquivo PDF contendo Proposta + Anexos.

## 5. Casos de Uso

1.  **Visualizar Previa**: Usuário clica em "Ver PDF" no dashboard. O sistema gera on-the-fly e abre em nova aba.
2.  **Download Final**: Usuário clica em "Baixar PDF". Sistema gera, faz merge dos manuais e entrega o download.
3.  **Exportar Word**: Usuário clica em "Baixar DOCX". Sistema gera documento convertendo tabelas e imagens para formato Word.

## 6. Critérios de Aceite
- [ ] Engine PDF implementada com `@react-pdf/renderer`.
- [ ] Layout seguindo a identidade visual (Capa, Cabeçalho, Rodapé).
- [ ] Renderização correta da Hierarquia (Local > Trecho > Tabela de Itens).
- [ ] Inclusão das Imagens Anotadas (`composed_url`) em alta qualidade.
- [ ] Engine DOCX básica implementada (exportação de conteúdo).
- [ ] Feature de Merge de PDFs (Proposta + Manuais) funcional.
