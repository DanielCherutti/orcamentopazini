# 20260202120000000 - Grupos de Produtos

Esta especificação define os requisitos para Grupos de Produtos no sistema Pazini, permitindo agrupar produtos para organização do catálogo e inclusão em lote nos orçamentos.

## 1. Contexto e Objetivo

- **Contexto**: O catálogo de produtos cresce e precisa de organização. Orçamentos frequentemente incluem conjuntos de produtos relacionados (ex.: "Kit Guarda-Corpo", "Linha de Sinalização").
- **Objetivo**: Introduzir o conceito de **Grupo de Produtos** para:
  1. Agrupar produtos no cadastro.
  2. Permitir adicionar um grupo inteiro a um trecho do orçamento em uma única ação.
- **Escopo**: Cadastro de grupos, associação produto↔grupo, UI de seleção com criação inline, e ação "Adicionar Grupo" no orçamento.

## 2. Requisitos Funcionais

### 2.1 Cadastro de Grupos (Produto)

- Cada produto pode pertencer a **zero ou um** grupo.
- No formulário de produto (Aba Básico), o campo **Grupo** deve:
  - Ser exibido como **seleção em lista** (Combobox/Select).
  - Listar todos os grupos cadastrados ordenados por nome.
  - Permitir **cadastro de novo grupo** quando a opção desejada não existir:
    - Opção "Criar novo grupo..." no final da lista.
    - Ao selecionar, abrir campo inline ou modal para digitar o nome do novo grupo.
    - Ao confirmar, criar o grupo e associá-lo ao produto em uma única operação.
  - Permitir valor vazio ("Nenhum") para produtos sem grupo.

### 2.2 Gestão de Grupos

- Grupos são entidades independentes (podem existir sem produtos).
- Não há tela dedicada de CRUD de grupos nesta entrega; criação ocorre apenas via formulário de produto ou via ação "Adicionar Grupo" no orçamento (se o grupo for novo).
- Um grupo pode ser reutilizado por vários produtos.

### 2.3 Orçamento – Adicionar Grupo

- No trecho (section) do orçamento, além de "Adicionar Produto", deve existir a ação **"Adicionar Grupo"**.
- Ao acionar:
  - Exibir seletor de grupo (Combobox com lista de grupos que possuem produtos).
  - Ao selecionar um grupo, o sistema adiciona **todos os produtos** daquele grupo ao trecho, cada um como um item com quantidade padrão (ex.: 1) e preço atual do produto.
  - O usuário pode ajustar quantidades após a inclusão.
- Se o grupo selecionado não tiver produtos, exibir mensagem informativa e não adicionar itens.

### 2.4 Listagem de Produtos

- Opcional nesta entrega: filtro por grupo na listagem. Se implementado, deve ser um Select com grupos + opção "Todos".

## 3. Modelo de Dados

### 3.1 Nova Entidade: `product_group`

```typescript
type ProductGroup = {
  id: string;           // record (ex: product_group:uuid)
  company_id: number;    // 0 (padrão temporário)
  name: string;         // Nome do grupo (ex: "Kit Guarda-Corpo")
  description?: string; // Opcional, para uso futuro
  created_at: string;  // ISO
  updated_at: string;  // ISO
}
```

### 3.2 Alteração em `product`

- Adicionar campo opcional: `group_id?: string` (record<product_group>).

### 3.3 Schema SurrealDB (DDL)

```sql
DEFINE TABLE product_group SCHEMAFULL;
DEFINE FIELD company_id ON product_group TYPE int DEFAULT 0;
DEFINE FIELD name ON product_group TYPE string;
DEFINE FIELD description ON product_group TYPE option<string>;
DEFINE FIELD created_at ON product_group TYPE datetime;
DEFINE FIELD updated_at ON product_group TYPE datetime;

DEFINE INDEX product_group_name ON product_group FIELDS name;

-- Alteração em product (migração)
DEFINE FIELD group_id ON product TYPE option<record<product_group>>;
```

## 4. Contratos e Interfaces

### 4.1 Server Actions

- `listProductGroups()`: Retorna `{ success, data: ProductGroup[] }` ordenados por `name`.
- `createProductGroup(data: { name: string })`: Cria grupo e retorna `{ success, data: ProductGroup }`.
- `getProductGroupProducts(groupId: string)`: Retorna produtos do grupo para a ação "Adicionar Grupo".

### 4.2 UI – Formulário de Produto

- **Campo Grupo**: Combobox com:
  - Opção "Nenhum" (valor vazio).
  - Lista de grupos existentes.
  - Opção "Criar novo grupo..." que dispara fluxo de criação inline/modal.
- Ao criar novo grupo: chamar `createProductGroup`, atualizar lista local e selecionar o novo grupo.

### 4.3 UI – Orçamento (Trecho)

- Botão/link **"Adicionar Grupo"** ao lado de "Adicionar Produto".
- Modal ou Popover com:
  - Combobox de grupos (apenas grupos que possuem pelo menos 1 produto).
  - Ao selecionar: chamar `addGroupToSection(sectionId, groupId, budgetId)` que insere todos os produtos do grupo como itens (quantidade 1, preço atual).

### 4.4 ProductSelector

- Manter comportamento atual (busca por produto individual).
- O ProductSelector continua sendo usado para adicionar produtos um a um; "Adicionar Grupo" é uma ação separada.

## 5. Fluxos

### 5.1 Cadastrar Produto com Novo Grupo

1. Usuário abre formulário de novo produto.
2. No campo Grupo, seleciona "Criar novo grupo...".
3. Sistema exibe input para nome (inline ou modal).
4. Usuário digita "Kit Sinalização" e confirma.
5. Sistema cria o grupo e associa ao produto.
6. Usuário preenche demais campos e salva.
7. Produto é criado já vinculado ao grupo.

### 5.2 Adicionar Grupo ao Trecho

1. Usuário está no trecho "Linha de Montagem" do orçamento.
2. Clica em "Adicionar Grupo".
3. Seleciona "Kit Guarda-Corpo" (grupo com 3 produtos).
4. Sistema adiciona 3 itens ao trecho (um por produto, qtd 1).
5. Usuário ajusta quantidades conforme necessário.

### 5.3 Estados Alternativos

- Grupo sem produtos: ao tentar "Adicionar Grupo" com grupo vazio, exibir toast "Este grupo não possui produtos cadastrados."
- Erro ao criar grupo: exibir mensagem de erro e manter formulário aberto.
