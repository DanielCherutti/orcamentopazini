# Spec: CRUD de Grupos de Produtos com Imagem

**ID:** 20260223120000000
**Status:** Aprovado
**Data:** 2026-02-23

---

## 1. Contexto e Objetivo

Atualmente os grupos de produtos (`product_group`) só são gerenciados de forma inline, dentro do formulário de produto (criar um grupo na hora). Não existe tela dedicada para listar, editar ou excluir grupos, nem suporte a imagem por grupo.

O objetivo é criar um módulo completo de CRUD para grupos, com upload de imagem por grupo, e exibir o thumbnail dessa imagem no seletor de grupo no cadastro de produto.

---

## 2. Requisitos Funcionais

### RF01 — Listagem
- Tabela com: thumbnail (ou placeholder), nome, nº de produtos vinculados, data de criação, ações (editar, excluir)
- Busca por nome (URL-first)
- Paginação
- Ordenação por nome (locale pt-BR)

### RF02 — Criação
- Campos: nome (obrigatório), imagem (opcional, max 2MB, jpg/png/webp)
- Upload via Server Action com `saveFile(file, "product-groups")`
- Validação Zod: nome min 1 char, nome único por company_id

### RF03 — Edição
- Mesmos campos
- Substituição de imagem: apaga a anterior com `deleteFile()` antes de salvar nova
- Possibilidade de remover imagem existente

### RF04 — Exclusão
- Confirmação via AlertDialog
- Verifica produtos vinculados
- Exclui o grupo E remove o `group_id` do array `group_ids` de todos os produtos vinculados
- Apaga a imagem do disco via `deleteFile()`

### RF05 — Seletor Atualizado no Cadastro de Produto
- `ProductGroupSelector` mostra thumbnail (~32px) ao lado do nome em cada opção da lista
- Caso sem imagem: ícone placeholder (`Layers` do lucide-react)

## 3. Contratos e Interfaces

### Tipo atualizado

```typescript
export type ProductGroup = {
  id: string;
  company_id: number;
  name: string;
  description?: string;
  image_url?: string;  // NOVO
  created_at: string;
  updated_at: string;
};
```

### Novas Server Actions

```typescript
// Criar (com imagem)
createProductGroupAction(formData: FormData): Promise<ActionResult>

// Atualizar (com imagem)
updateProductGroupAction(id: string, formData: FormData): Promise<ActionResult>

// Excluir (desvincular produtos + apagar imagem)
deleteProductGroupAction(id: string): Promise<ActionResult>

// Obter por ID (para tela de edição)
getProductGroupAction(id: string): Promise<{ success: boolean, data?: ProductGroup }>
```
